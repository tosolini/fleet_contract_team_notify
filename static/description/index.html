Fleet Contract Team Notify

Extend Odoo's fleet contract notification system with configurable teams and multiple recipients.

Key Features

Core

  • Notification Teams: Create reusable teams with internal users
  • Team Assignment: Assign a team to each contract for notification management
  • Backward Compatibility: Original user_id field remains functional

Notifications

  • Multiple Email CC: Team members automatically receive email notifications
  • Automatic Followers: Team members added as contract followers
  • Activities: Create expiry activities for all team members
  • Email Templates: Predefined templates for expiry and new contract notifications

User Interface

  • Dedicated Section: Contract form with "Team Notifications" section
  • Filters and Grouping: List views with team filters
  • Configuration Menu: Dedicated menu to manage teams
  • Tag Widgets: Intuitive visualization with colored tags

Quick Start

1. Create a Team

  1. Navigate to Fleet → Configuration → Contract Teams
  2. Create a new team with a name (e.g., "Maintenance Team")
  3. Add team members from internal users

2. Assign Team to Contract

  1. Open or create a fleet contract
  2. In the "Team Notifications" section, select the team
  3. The "Users to Notify" field populates automatically
  4. Optionally add more users manually

3. Automatic Notifications

Team members will receive:

  • Emails as CC when notifications are sent
  • Internal Notifications as contract followers
  • Activities for expiry reminders (via scheduler)

Technical Details

Models

fleet.contract.team: New model for notification teams

  • Fields: name, description, user_ids, active, contract_count
  • Methods: action_view_contracts()

fleet.vehicle.log.contract (extended):

  • New fields: team_id, notify_user_ids
  • Automatic follower management
  • Methods for activities and email notifications

Integration

Fully compatible with standard Odoo Fleet module and OCA fleet extensions.

Dependencies

  • fleet - Standard Odoo Fleet module
  • mail - Messaging and notification system
